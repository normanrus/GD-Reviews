# GD Reviews

GD Reviews is a lightweight mod that adds a review button to every level, letting you read reviews stored locally - right from the level menu.

## Usage

When you open the menu of any level, an extra button with a custom icon appears. Click it to open a popup with the review text for that level.

If a review exists for the level, it will be shown in a clean popup window. If not, a warning will appear letting you know that no review has been written yet.

## Features

* Custom review button added to every level menu
* Own texture for the button
* Reviews loaded from a <cg>local file</c>
* Popup with review text when a review is available
* Warning popup when no review is found
* Lightweight and simple — no external servers required
